# DIGITAL FRAGMENTS

[View the website](https://pengxuan-jing.github.io/digital-fragments/)

An interactive glitch photography portfolio built from our [original p5.js sketch](https://editor.p5js.org/tonyllt666/sketches/Zf60KqPUV). The fixed animated background stays in place while the page scrolls through four subjects and a gallery of 15 photographs.

## Files

- `index.html` and `style.css` — page layout and visual design
- `sketch.js` — original p5 background and glitch animation
- `gallery.js` — scroll reveal and floating motion for the photo gallery
- `archive/` — all 15 gallery photographs
- `portrait*.jpg`, `face.png`, `asset-data.js`, and `vendor/p5.min.js` — original animation assets and local p5 runtime

## Run locally

Download the repository and open `index.html` in a browser. No installation or build step is needed.
